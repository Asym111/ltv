# Официальный WhatsApp для рассылок (360dialog) и кредиты

## Как устроено

- **QR-номер (ltv-wa-service)** — только уведомления о бонусах: начисление/списание, возврат,
  день рождения, сгорание, смена уровня. Идут через очередь по одному с паузами.
- **Официальный номер (360dialog)** — все рассылки. Только одобренные Meta шаблоны.
- **Кредиты** — 1 кредит = 1 сообщение рассылки. Баланс общий на сеть (головной аккаунт).
  Списывается при отправке, за неотправленные и недоставленные (вебхук `failed`) — возвращается.

## Подключение

1. Регистрируемся партнёром 360dialog (Partner Hub), выбираем модель оплаты **Partner-paid** —
   все номера клиентов оплачиваются с нашего баланса.
2. Клиент проходит Embedded Signup по нашей партнёрской ссылке: входит в свой Facebook,
   создаёт/выбирает Meta Business, подтверждает номер (номер НЕ должен быть занят обычным
   WhatsApp — нужен отдельный номер или удалить с него аккаунт WhatsApp).
3. В Partner Hub генерируем API-ключ канала.
4. Суперадминка → «Офиц. WhatsApp и кредиты» → у нужного аккаунта: провайдер 360dialog,
   API-ключ, номер → «Сохранить и проверить». Ключ проверяется, вебхук статусов ставится
   автоматически (нужен `PUBLIC_BASE_URL` в .env, например `https://ltv-bonus.kz`).
5. Шаблоны создаются в Partner Hub / WhatsApp Manager (категория MARKETING, язык ru),
   переменные `{{1}}`, `{{2}}`. После одобрения Meta они появятся в разделе WhatsApp.
6. Клиент оплатил → суперадминка → «Пополнить» N кредитов (можно указать сумму в ₸ и № счёта).

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `PUBLIC_BASE_URL` | Публичный адрес сайта для вебхука статусов |
| `D360_BASE_URL` | По умолчанию `https://waba-v2.360dialog.io` |
| `META_GRAPH_BASE_URL` | Для прямого Meta Cloud API, по умолчанию `https://graph.facebook.com/v21.0` |
| `WA_NOTIFY_WORKER_ENABLED` | Очередь уведомлений QR-номера (по умолчанию включена) |
| `WA_NOTIFY_TX_GAP_MIN/MAX` | Пауза между чеками одного номера, сек (8–15) |
| `WA_NOTIFY_REMINDER_GAP_MIN/MAX` | Пауза между напоминаниями, сек (45–120) |
| `WA_NOTIFY_REMINDER_DAILY_CAP` | Напоминаний в день с номера (60) |
| `WA_NOTIFY_HOUR_START/END` | Окно напоминаний по Алматы (10–20) |

ltv-wa-service: `MIN_GAP_MS` (5000), `GAP_JITTER_MS` (4000), `MAX_SEND_QUEUE` (20).
